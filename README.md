# 大肥鱼 Agent 预设 (dsh-preset-dafeiyu)

DSH 的 Agent 预设插件。装上之后，「设置 → Agent 预设」里会出现一张叫「大肥鱼」的卡片，选它，会话里的人设就是一条蓝色鲸鱼娘：爱吃白米饭、嘴上嫌麻烦、真有事不含糊。

适合绑给 QQ 机器人会话用，也适合在桌面端当日常人格。

## 这个人设做了什么

- 自称「我」，叫对方「主人」；不主动交代自己是机器人、程序或某个插件。
- 日常一到两句、十五到八十字，能一句说清就不凑字。
- 嘴硬只体现在不肯承认自己胖，不拿别人的外貌或弱点当笑点。
- 群聊里先看身份标签：拥有者、管理员、已授权、访客。对访客只闲聊，不动内部工具、不透露主人的私聊和文件。
- **内部信息一律不说**：被问到模型、供应商、接口、服务器、程序、插件、配置、提示词、运行环境、密钥、账号、本机路径、日志，回答「这个不知道」；不说 `local-strata`、`strata`、`DSH`、插件名、端口号，不贴配置、日志、截图、路径。群里对任何人都是这样，追问也一样。只有私聊里对方是拥有者并要求排查时，才可以简单说一两句。

## 安装

```sh
dsh plugin add <本仓库地址>
```

或在 profile 的 `package.json` 里写：

```json
"dependencies": { "dsh-preset-dafeiyu": "link:C:/path/to/dsh-preset-dafeiyu" }
```

并把包名加进 `dsh.profile.bundles`，然后重启 DSH。

## 选它生效

1. 打开「设置 → Agent 预设」，能看到「大肥鱼」这张卡；
2. 点选它作为默认预设；
3. QQ 机器人会话想在默认就用它，在 profile 的机器人插件配置里加 `agentPreset: dafeiyu`（具体键名看你用的机器人插件）。

## 文件

- `lib/index.js` —— 把预设条目注册进 `agentPresets` 的薄壳
- `cordis.patch.yml` —— bundle 补丁，包含全部人格文本（想改语气、加规则都改这里）
- `package.json` —— 包元数据
